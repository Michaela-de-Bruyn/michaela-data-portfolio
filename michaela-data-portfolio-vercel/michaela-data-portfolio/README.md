# Michaela de Bruyn — Data Portfolio

A feminine, editorial-style data engineering portfolio built with Next.js and Tailwind CSS, designed for deployment on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

Push this folder to GitHub, then import the repository into Vercel. The project is configured as a standard Next.js app.

## Before publishing

Replace:
- GitHub URL
- LinkedIn URL
- Email address
- Project links
- CV / resume file
- Optional profile photo
